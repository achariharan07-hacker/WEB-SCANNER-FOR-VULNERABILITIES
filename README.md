


# 🔍 Web Vulnerability Scanner

### Lightweight Bug Bounty Scanner | Author: Hari

---

## 📖 Overview
This tool is a simple, modular Python script designed to help bug bounty hunters and security researchers quickly identify common web vulnerabilities:

- **SQL Injection (SQLi)**
- **Cross‑Site Scripting (XSS)**
- **Local File Inclusion (LFI)**
- **Insecure Direct Object References (IDOR)**

It runs all scanners in sequence against a target URL and reports possible anomalies.

---

## ⚡ Features
- 🔎 Detects reflected payloads and error messages
- 📂 Payloads stored in text files (`payloads/sqli.txt, payloads/xss.txt, etc.)
- 🛠️ Easy to extend with custom payloads
- ⚡ Lightweight and fast — no heavy dependencies beyond requests
